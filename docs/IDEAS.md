# Bro Chase: Ideas

> Idea backlog. Every thread adds new ideas here with a short note on how it makes the game better.

> Before adding, check [SCOPE.md](SCOPE.md) "Out of scope" so we don't suggest something Moiz already said no to.

Status: 💡 new · 👍 Moiz likes it · 🚧 being built · ✅ shipped · ❌ dropped

## Performance and graphics

| Idea | How it makes the game better | Status |
| --- | --- | --- |
| Instance and merge static scenery (houses, trees, cars, lamps) | Far fewer draw calls, so higher FPS on laptops and phones | ✅ |
| Graphics quality setting (Low / Medium / High) with auto-detect | Weak devices stay smooth, strong ones look great | ✅ auto, `?fx=0/1/2` to force; a menu toggle is still 💡 |
| Rigged, animated character models (CC0) for bros and Opps that still take the custom look | Characters stop looking like stacked shapes; biggest remaining visual gap | 💡 |
| Real models for street props (lamps, manholes, benches, bins) and crib walls with windows | The play area matches the new town around it | 💡 |
| Babylon Inspector behind `?inspect` (dev only, lazy-loaded) | Click any object in the running game to see and tweak it, so graphics fixes go much faster | 💡 |
| Use Babylon's GPU particles and glow layer for neon, lamps and ring lights | Brighter, cheaper glow effects that make the night modes pop | 💡 |
| FPS counter toggle (F3) | Makes slowdowns easy to spot and report | 💡 |
| Day-to-sunset sky over the night | The night feels like it moves forward, while the game stays bright | 💡 |
| Weather events (rain puddles, wind) as short modes | More variety, and rain can hide footsteps for a moment | 💡 |

## Gameplay

| Idea | How it makes the game better | Status |
| --- | --- | --- |
| Crib windows the Opps can peek through or smash | A second, slower way in, so both doors aren't the only thing to defend | 💡 |
| Hiding spots (wardrobe, under the bed, dumpster) | A last-second escape when you can't reach a friend's crib | 💡 |
| Boss Opp on the last minute of the night ("Big Opp") | A big finale that makes the end of each night exciting | 💡 |
| Opp types (fast, tank, screamer) unlocked as the night goes on | Keeps the night from feeling the same start to finish | 💡 |
| Daily challenge ("survive without sprinting") with a cash bonus | A reason to come back each day | 💡 |
| Team goals (all bros survive = bonus cash for everyone) | Rewards helping friends instead of going solo | 💡 |
| Spectate mode while caught (watch friends, ping Opps) | Caught players stay involved instead of waiting | 💡 |
| Opp perks for player Opps (silent steps, longer screech) | Playing as an Opp gets deeper and more replayable | 💡 |
| Trade or gift cash between bros | More teamwork, and a way to repay someone who let you in | 💡 |

## Social and progression

| Idea | How it makes the game better | Status |
| --- | --- | --- |
| Friends list and "join friend" button | Easier to play with the same people again | 💡 |
| Emotes and meme voice lines on a wheel | Fun, fits the brain-rot theme, and lets players talk without typing | 💡 |
| Crib decorating (posters, rugs, neon signs) | Players feel ownership of their crib and show off | 💡 |
